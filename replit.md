# ski-wekan-mongodb

A Node.js/Express server for a Wekan-style kanban board with MongoDB.

## Stack
- Runtime: Node.js 20
- Framework: Express
- Database: MongoDB (to be configured via MONGODB_URI env var)

## Running
- Workflow: "Start application" → `node server.js` on port 5000
